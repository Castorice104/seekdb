# Async AI Column Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for the coordinating implementation and superpowers:dispatching-parallel-agents for independent DDL and worker domains. Checkboxes track completion.

**Goal:** Implement the approved asynchronous AI COLUMN specification in seekdb and verify it against real local SQL and deterministic Mock services.
**Architecture:** Persist AI definitions in Schema and metadata tables; maintain invalidation and durable tasks inside the originating transaction. A database-owned background service calls existing AI providers outside write transactions and atomically publishes version-guarded groups. Native SQL resolution handles RETRY and column-wide strict reads.
**Tech Stack:** C++17, seekdb Schema/DML, CMake, gtest, mysqltest, Python Mock, WSL Ubuntu-22.04.
**Spec:** C:/Users/wyh20/Documents/ChatGPT/OceanBase/AI列-设计与现状核查.md (approved by user 2026-10-28).

## Global Constraints
- MySQL and sync_mode='async'; no chained AI columns.
- Never call external models before business commit, or for rolled-back changes.
- No hardcoded model/input/primary-key/Mock response logic.
- All same-change AI columns publish terminal results and statuses in one transaction.
- Default unfinished/failed results NULL; READY NULL must remain distinguishable.
- Strict read checks whole referenced AI columns, before row filtering and writes.
- Preserve previous AI function and file-as-database changes, and existing uncommitted work (snapshot already saved).
- Source workspace remains existing feature branch to reuse the large configured build; do not reset/stash existing work.
- No official score submission; no real model calls; compile at -j2.

## Review Focus
- Explicit transactions and statement/savepoint rollback leave no task or external call.
- An old group partially superseded by RETRY still completes its surviving columns.
- String/composite primary keys and SQL quoting do not misdirect writes.
- Lease recovery and delayed old workers cannot overwrite or delete newer tasks.
- READY NULL passes strict read; pending columns hidden by WHERE still fail.
